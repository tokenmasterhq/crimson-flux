只从官方网页复制

另开一个普通 Chrome 或 Edge 标签页，在官方网页完成全部验证；下面的操作都在那个官方网页标签页中进行。

打开官方网页
5 步安全导入方法
  1. 打开开发者工具

    在官方网页按 F12（macOS 可按 ⌥⌘I），然后选择 Network。

  2. 开始录制并刷新

    确认录制圆点为红色，清空旧记录后刷新官方网页，让最新请求出现在列表中。

  3. 筛选账号验证请求

    在筛选框输入 /api/sns/web/v2/user/me，选择最新且状态正常的 user/me 请求。

  4. 只复制 Cookie 的值

    进入 Headers → Request Headers，找到 Cookie:，复制冒号之后的完整值，其他内容不要复制。

    不要使用 document.cookie、Copy as cURL，也不要复制整块 Request Headers。

  5. 回到本页保存并清理

    粘贴到“官方网页登录态 Cookie”输入框并点击“验证并加密保存”。成功后输入框会清空；请再复制一段普通文字，覆盖系统剪贴板。

导入失败怎么办？
  • 确认官方网页已完成全部验证，并保持登录状态。
  • 刷新页面后重新选择最新的 user/me 请求。
  • 确认内容仅为 Cookie: 后面的值，没有前缀、换行或其他请求头。
  • 若登录态已经过期，请重新登录后再按上述步骤复制。
